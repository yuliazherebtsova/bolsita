# Bolsita

Легкий PWA-список покупок с локальным хранением и русским голосовым вводом через Web Speech API.

## Команды

```bash
npm install
npm test
npm run build
npm run dev
```

Для проверки production PWA:

```bash
npm run build
npm run preview
```

Голосовые команды v1:

- `добавь хлеб`
- `добавить молоко`
- `добавь в список сыр`
- `удали хлеб`
- `убери молоко`
