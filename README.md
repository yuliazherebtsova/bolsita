# Bolsita

Легкий PWA-список покупок с локальным хранением и русским голосовым вводом через Web Speech API.

## Команды

```bash
npm install
npm test
npm run build
npm run dev
```

Для проверки production PWA:

```bash
npm run build
npm run preview
```

## GitHub Pages

Production URL после деплоя:

https://yuliazherebtsova.github.io/bolsita/

В настройках репозитория GitHub Pages должен быть выбран источник `GitHub Actions`.

## Обновления и данные

Список хранится только на устройстве, в `localStorage` под ключом `bolsita.items.v1`.
Версия этого ключа относится к формату данных, а не к релизу. Обновления читают существующий список без изменения названий, отметок и идентификаторов.

При сборке service worker получает версию по содержимому файлов приложения. Обновление заменяет только кеш оболочки `bolsita-shell-*`; данные списка не очищаются. Адрес запуска и идентификатор PWA остаются `/bolsita/`.

Чтобы получить новую версию, закройте и снова откройте приложение с подключением к сети. Если оно было открыто во время установки обновления, может потребоваться ещё один запуск. Удалять приложение или очищать данные сайта не нужно. Перенос на другой домен, другой телефон, переустановка и очистка данных браузера не являются обновлением и не гарантируют сохранение локального списка; облачной копии нет.

Механизм проверки обновлений: [ServiceWorkerRegistration.update](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/update).

Голосовые команды v1:

- `добавь хлеб`
- `добавить молоко`
- `добавь в список сыр`
- `удали хлеб`
- `убери молоко`
